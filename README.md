# Recordatorio de Citas — Artigas Abogados

Generador de mensajes de WhatsApp para **confirmaciones y recordatorios de citas**.
Página **estática** (`index.html`) instalable como **PWA**, optimizada para **GitHub Pages**.

## Demo (GitHub Pages)
1. Sube todos los archivos al repositorio (index.html, manifest.webmanifest, service-worker.js e iconos).
2. Activa **Settings → Pages → Deploy from a branch → main / (root)**.
3. La app quedará accesible públicamente e instalable en el móvil.

## Archivos
- `index.html` — aplicación completa (HTML + CSS + JS embebidos)
- `manifest.webmanifest` — manifiesto PWA
- `service-worker.js` — service worker mínimo
- `icon-180.png` / `icon-192.png` / `icon-512.png` — iconos de instalación

## Uso local
Abre `index.html` en tu navegador. No requiere servidor ni dependencias.
